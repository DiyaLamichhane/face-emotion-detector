# 🧠 Face Emotion Detector

Real-time face detection and emotion recognition using face-api.js

## ✨ Features
- 🎥 Real-time face detection from webcam
- 😊 7 emotion detection: Happy, Sad, Angry, Fearful, Disgusted, Surprised, Neutral
- 📊 Live emotion confidence scores with progress bars
- 🎯 Dominant emotion display with confidence percentage
- ⚡ Optimized for speed (results in 3-8 seconds)
